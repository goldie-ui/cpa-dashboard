# 회계사 시험 준비 대시보드

CPA 수험에 자주 쓰는 사이트와 공부 도구를 한 곳에 모아둔 개인용 대시보드입니다.

**바로가기:** https://cpa-goldie.vercel.app

미러(동기화 미지원): https://goldie-ui.github.io/cpa-dashboard/

## 기능

- 수험 사이트 11곳 바로가기 (클릭 시 새 탭)
- ⭐ 즐겨찾기 고정 · 검색 필터
- 시험일 D-day 카운터
- 수험 명언 20초마다 자동 교체 (클릭하면 바로 다음)
- ⏱ 포모도로 타이머 25/5분 — 완료하면 선택한 과목에 자동 적립
- ✅ 오늘 할 일 체크리스트 (매일 자동 비우기 옵션)
- 📝 메모 패드 (자동 저장)
- 🌱 과목별 공부시간 잔디밭 — 18주 히트맵, 연속 일수, 과목별 막대
- 라이트/다크 모드 (기기 설정 자동 + 토글 버튼)
- 💾 백업 내보내기 / 불러오기 — 기기 간 기록 이동, 브라우저 정리 대비
- 📱 노트북 · 아이패드 · 폰 대응 (홈 화면에 추가하면 앱처럼 전체화면 실행)

## 기기 동기화

푸터의 **기기 동기화**를 켜면 노트북·폰·아이패드의 기록이 하나로 합쳐집니다.

1. 한 기기에서 **이 기기에서 시작** → 동기화 코드 생성
2. 다른 기기에서 그 코드를 붙여넣고 **연결**

이후에는 변경 시 자동 저장(3초 디바운스)되고, 탭으로 돌아올 때 최신 내용을 받아옵니다.

| 항목 | 충돌 시 규칙 |
|---|---|
| 공부 기록 | 날짜·과목별 **더 큰 값** 유지 — 합쳐지며 유실 없음 |
| 메모 · 할 일 · 즐겨찾기 · D-day | **마지막에 고친 쪽**이 남음 |

동기화를 켜지 않으면 기록은 브라우저 localStorage에만 남고 서버로 가지 않습니다.
켜면 Vercel Blob **private 스토어**에 저장되며, 동기화 코드를 SHA-256 해시한 경로를 쓰므로
저장소에는 코드 원문이 남지 않고 인증 없는 직접 접근은 403으로 차단됩니다.

> ⚠️ 동기화 코드를 아는 사람은 기록을 볼 수 있습니다. 남에게 알려주지 마세요.

### 백업 파일

불러오기는 **병합** 방식입니다. 같은 파일을 여러 번 불러와도 기록이 중복 합산되지 않습니다.

| 항목 | 병합 규칙 |
|---|---|
| 공부 기록 | 날짜·과목별로 **더 큰 값**만 남김 |
| 즐겨찾기 · 할 일 | 없는 것만 추가 |
| 메모 | 비어 있으면 채우고, 다르면 아래에 이어붙임 (이미 있으면 그대로) |
| D-day | 설정 안 돼 있을 때만 가져옴 |

## 수정 방법

`index.html` 위쪽 세 개의 배열만 고치면 됩니다.

**사이트 목록** — `DATA`

```js
{ title:"분류 이름", icon:"📋", items:[
  {name:"사이트 이름", url:"https://example.com", desc:"설명"},
]},
```

**과목 목록** — `SUBJECTS`

```js
{name:"재무회계", color:"#3ddb9f"},
```

**명언 목록** — `QUOTES` (`QUOTE_MS`로 교체 주기 조절)

```js
{t:"문구 내용"},
{t:"인용 문구", by:"출처"},
```

수정 후 push하면 약 40초 내로 자동 배포됩니다.

```bash
git add -A && git commit -m "수정 내용" && git push
```
